GPX Merge

Combine recordings of the same ride from different devices: power from one, heart rate from another, the GPS track from whichever is complete. Reads GPX and FIT files and writes one GPX file. Everything runs in this page. Your files never leave your computer.

1. Recordings

The base file supplies the GPS track and timestamps. Clock offsets are detected automatically from cadence (or GPS speed); adjust them if needed.

None of these recordings has a GPS track, so there is no route to write. Add one that does.

2. What comes from where

Gaps are filled by drawing a line between the readings either side. A power or cadence gap that ends in a zero is the start of a coast, so it is filled with 0.

3. Preview

Nothing is uploaded. Open index.html straight from disk, or host it anywhere static.
